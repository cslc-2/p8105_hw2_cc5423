# Problem 1

**Reading in the csv data file, cleaning names, keeping the variables we
want, and converting the entry variable from character to logical:**

``` r
transit_df =
  read_csv("data/NYC_Transit_Subway_Entrance_And_Exit_Data.csv", na = c("","NA",".")) |> 
  janitor::clean_names() |> 
  select(line:entry, vending, ada) |> 
  mutate(
    entry = recode_values(
      entry,
      "YES" ~ TRUE,
      "NO" ~ FALSE
    ))
```

This dataset currently includes the following variables: line,
station_name, station_latitude, station_longitude, route1, route2,
route3, route4, route5, route6, route7, route8, route9, route10,
route11, entrance_type, entry, vending, ada. These variables contain
values for the station line, its name, location, routes that it serves,
entrance type, entry, vending, and ADA compliance. I read in the
original csv file and cleaned the variable names so they were in snake
case. Then, since it originally contained extra information that I did
not need (such as the division, staff and staff hours, and exit type), I
just kept the variables listed above. Lastly, I changed the entry
variable from a character (YES/NO) to logical (TRUE/FALSE).

# Problem 3

Initial import, cleaning, and tidying of baseline dataset:

``` r
baseline_df =
  read_csv("data/data_mci/MCI_baseline.csv", skip = 1, na = c("","NA",".")) |> 
  janitor::clean_names() |> 
  mutate(sex = recode(sex, `1` = "male", `0` = "female"),
         apoe4 = recode(apoe4, `1` = "carrier", `0` = "non-carrier")) |> 
  filter(is.na(age_at_onset) | age_at_onset >= current_age)
```

- Import baseline dataset, which is a csv file, skipping the first row,
  which is a header.
- Clean variable names using janitor package
- Recode `sex` and `apoe4` so they are not numeric and instead have
  labeled categories
- Remove participants that have MCI at baseline.

The baseline dataset `baseline_df` provides information on the
participants’ id, baseline age, sex, years of education, whether they
are a carrier of APOE4, and age of onset of MCI if they did get MCI
during the follow-up. This dataset has 480 observations or participants
recruited, and 6 variables. Of these participants, 94 participants
develop MCI. The average baseline age is 65.03 years. 63/210, or 0.3 of
the women in the study are APOE4 carriers.
